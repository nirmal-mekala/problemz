# Longest Unique Substring Length

## Problem
Given a string, return the length of the longest substring that contains no repeating characters.

## Function Signature
`longestUniqueSubstringLength(value: string): number`

## Examples
- `"" -> 0`
- `"abcabcbb" -> 3` ("abc")
- `"bbbbb" -> 1` ("b")
- `"pwwkew" -> 3` ("wke")
